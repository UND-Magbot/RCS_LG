------------------------------------------------------------
 기록 중에 — 비이상적 정지를 봤을 때
------------------------------------------------------------

 서버PC 앞   검은 창(주행 기록기)에서  [스페이스바]
 로봇 옆     폰으로 현장콘솔 열고      [비이상적 정지] 버튼
             (메모 칸에 "랙 앞", "코너" 처럼 적어도 됨)

 둘 다 같은 파일에 모입니다. 느끼자마자 누르세요.

 폰 주소: 현장콘솔.bat 실행 → 화면에 뜨는  http://<서버PC IP>:8777
 현장콘솔에도 [기록 시작] [종료·추출] 버튼이 있습니다 (bat 과 같은 기능).


------------------------------------------------------------
 지키세요
------------------------------------------------------------

 1. 검은 창(주행 기록기)은 닫지 마세요. 닫으면 주행 기록이 거기서 끊깁니다.
 2. 시작 전에 config.bat 의 ROBOT_IP 가 맞는지 확인.
 3. L2 는 로봇 bag 을 받느라 몇 분 걸립니다.
    "마지막 bag 녹화 중 — 기다리는 중" 이 나오면
      기다리면   → 최대 12분 뒤 zip 이 자동으로 갱신됩니다
      급하면     → 창을 닫아도 zip 은 이미 있습니다.
                   나중에 L3_bag다시받기.bat 로 빠진 것만 채웁니다.


------------------------------------------------------------
 zip 안에 들어가는 것
------------------------------------------------------------

 인덱스.txt      ★ 먼저 열 파일. 표시 목록 · 망 요약 · 빠진 것과 이유
 marks.jsonl     비이상적 정지 표시 (스페이스바 + 폰)
 drive_log\      주행 기록 (속도 · 센서 · 장애물 · 스냅샷 · 요약)
 서버\           백엔드 로그(세션 구간만) · 경고/오류 · 안전존 · 알람 · 설정 사본
 망\             ping 1초 간격 (로봇·라우터 2개) · HTTP 왕복 · tracert · ipconfig
 로봇\           로봇 bag (세션 앞뒤 5분) · 시작/종료 상태
 시계.jsonl      로봇-서버 시계 차이 (시작·종료)


------------------------------------------------------------
 알아둘 것 — 2026-09-28 에 bag 을 못 뽑은 이유
------------------------------------------------------------

 bag 파일명의 시각은 한국 시각이 아닙니다. 로봇 시간대로 붙습니다.
   사무실 crawler  UTC+8   (파일명 09:00 = 실제 10:00)
   현장 longjack   UTC 추정 (파일명 09:00 = 실제 18:00)

 이제 L2 가 bag 안의 실제 시각을 읽어 자동으로 맞춥니다.
 손으로 뽑을 때도 fetch_bags.py 에 한국 시각으로 넣으면 됩니다.


------------------------------------------------------------
 안 될 때
------------------------------------------------------------

 "이미 기록 중입니다"      L2 를 먼저 누르세요 (지난번에 안 끝낸 세션)
 인덱스에 X 로봇 bag       로봇 연결 확인 후 L3_bag다시받기.bat
 인덱스에 X 서버 로그      백엔드가 이 폴더에서 돌고 있는지 확인
 인덱스에 X 주행 기록      drive_log_화면.txt 를 열어 보세요
