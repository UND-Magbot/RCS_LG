 A. 사용폴더를 git 저장소로 (한 번만. 인터넷 되는 곳에서)
------------------------------------------------------------

 서버PC 는 폴더가 둘입니다.
   사용폴더    실제로 백엔드가 돌아가는 것.  git 없음
   업로드폴더  git 있음. 필요한 파일만 손으로 복사해 넣던 곳

 업로드폴더의 .git 만 사용폴더로 옮기면 폴더 하나로 끝납니다.
 git init + checkout 은 절대 쓰지 않습니다. 현장 수정분이 덮입니다.

   A1_git전환_백업과연결.bat    업로드폴더\현장작업\ 에서 실행
                                 백업 -> .git 복사 -> 차이 확인 후 멈춤

     ** 여기서 [M] 목록을 반드시 눈으로 보세요 **
     소스 코드(.py .html .tsx)가 있으면 현장에서 고친 것일 수 있습니다.
     확인 전에 A2 로 넘어가지 마세요.
     판단이 어려우면 일단 살립니다. 날아간 건 못 되살립니다.

   A2_git전환_기준점커밋.bat    .gitignore -> 새 브랜치 -> 커밋 -> push
                                 브랜치명: field/baseline-<오늘날짜>
                                 커밋 직전에 목록을 한 번 더 보여줍니다

 전환이 끝나면 그다음부터는 사용폴더에서 바로:
   git pull origin feature/lg_luke
