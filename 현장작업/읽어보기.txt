 A. 사용폴더를 git 저장소로 (한 번만. 인터넷 되는 곳에서)
------------------------------------------------------------

 서버PC 는 지금 폴더가 둘입니다.
   사용폴더    실제로 백엔드가 돌아가는 것.  git 없음
   업로드폴더  git 있음. 필요한 파일만 손으로 복사해 넣던 곳

 업로드폴더를 끼우지 않습니다.
 사용폴더 자체를 저장소로 만들어 새 브랜치로 바로 올립니다.

   A_사용폴더_git올리기.bat        <- 이것 하나면 됩니다

     백업(zip) -> .gitignore -> git init -> 원격 연결
     -> field/baseline-<오늘날짜> 브랜치 -> add
     -> ** 목록 보여주고 멈춤 ** -> 커밋 -> push

     ★ fetch / checkout 을 하지 않습니다.
       그래서 로컬 파일이 덮일 일이 없습니다.
       (위험한 것은 git init 이 아니라 그 뒤의 checkout origin/... 입니다)

     멈췄을 때 확인할 것:
       venv / node_modules / maps 가 목록에 보이면 n
       파일 수가 수천 개면 n
       보통 수백 개면 정상입니다

 전환 후 개발PC 코드를 받는 법 (통째 merge 금지 - 이력이 별개입니다):

   git fetch origin
   git checkout origin/feature/lg_luke -- scripts/load_test.py
   git checkout origin/feature/lg_luke -- tools/robot_monitor.html

 fetch 는 파일을 안 건드립니다. checkout 에 -- 뒤로 경로를 주면
 그 파일만 가져옵니다.
