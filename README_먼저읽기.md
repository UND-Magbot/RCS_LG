## 지금 상태 요약 (2026-08-13)

### 해결된 것
- 로봇에 랙 규격이 2개(LG2 + S600) 들어가 있던 문제 → **LG2 하나로 정리**
- LG2 규격 `0.64 × 0.545` **정확함을 실측 확인** (검출 성공 시 소수점까지 일치)
- 정면 자세에서 랙 인식 **100%** (20/20, 16/16)
- 스크립트가 랙을 끌고 가던 사고 2건 → **잭 판정 기준 수정 + 이동 전 안전 가드 추가**

### 진행 중인 문제
| 문제 | 상태 |
|---|---|
| `lidar_matched=False` (로봇이 자기 위치를 잘못 앎) | **충전소가 앵커 고정 안 돼 밀린 것이 원인으로 지목**. 맵 재작성 예정 |
| 랙이 틀어지면 인식 실패 | 허용 각도 **미측정**. 절차서 STEP 7-1 로 측정 예정 |
| 랙 반납이 `standard` 이동이라 위치가 어긋남 | `to_unload_point` 로 변경 검토 중 (**미적용**) |
| `align_with_rack` 회전 허용 파라미터 | `rack.specs` 에 없음. AutoXing 문의 필요 |

### 먼저 해야 할 물리 조치 ★
```
1. 충전소 C1 을 바닥에 앵커 고정      ← 위치재조정의 기준점
2. 랙 자리 R1 에 스토퍼·가이드 설치
3. 맵핑 전 랙·대차 전부 치우기        ← 안 치우면 지도에 다리가 박힘
```
**이걸 안 하고 맵을 따면 그 맵도 며칠 뒤 똑같이 어긋납니다.**

## Claude 에게 시킬 때

서버 PC에 Claude Code 를 설치한 뒤:

```
바탕화면의 RCS_LG_서버PC_구축가이드.md 를 읽고 §0.2 의
"1단계 — 지금 바로 가능" 부터 순서대로 진행해줘.
각 단계의 [확인] 명령을 실제로 실행해서 결과를 보여준 다음 넘어가줘.
```

서버 구축이 끝나면:
```
RCS_LG_맵핑_및_테스트_절차.md 대로 진행해줘.
```

두 문서 모두 맨 앞에 **Claude 용 지시문**이 들어 있습니다
(확인 명령을 실제로 실행할 것, 공란 값은 먼저 물어볼 것 등).

## 주의

- **고정 IP 는 아직 미정입니다.** 서버PC 구축가이드 §0.1 표를 채우고 시작하세요.
  사무실 망에서 세팅·테스트하는 데는 LG 현장 LTE 회선(U+ 승인 대기)과 무관합니다.
- 스크립트는 **Windows 전용**입니다 (`msvcrt` 키 입력 사용).
- 타임아웃 기본값은 **전부 추정치**입니다. 1사이클 실측 후 조정하세요.
- `[확인]` 버튼을 시간으로 대체하는 자동 사이클은 **테스트 전용**입니다. 현장 운영에 쓰지 마세요.
