## 2026-09-21 에 바뀐 것

### 1. 콘솔 좌·우 칸을 **배송 흐름**으로 묶음

종전에는 지점이 있는 **구역**(자재실 / EOL)으로 묶여서, 짝이 서로 다른 칸에 떨어져 있었습니다.

```
[ 종전 ]  좌: 자재실 출발 · 자재실 도착      우: EOL 도착 · EOL 출발
[ 변경 ]  좌: EOL 출발 · 자재실 도착        우: 자재실 출발 · EOL 도착
              └── 한 배송 흐름 ──┘              └── 한 배송 흐름 ──┘
```

**출발과 그 목적지가 같은 칸 위아래**에 오므로, 호출이 잠겼을 때 원인이 되는
지점이 바로 아래에 보입니다. 두 칸 모두 **출발이 위**입니다.

> 코드 수정 없이 `poi_labels.json` 의 구역 값만 바꾸면 이 배치가 됩니다.
> 화면은 **저장된 구역 글자가 같은 지점끼리** 묶고, 칸 순서는 **파일에 나온 순서**를 씁니다.

### 2. 이름을 저장해도 좌·우 순서가 안 뒤집히게

`GET /api/settings/poi-labels/editable` 이 목록을 **이름 사전순**(J1·J2·R1·R2)으로
다시 세우고 있었습니다. 화면은 그 순서대로 저장 요청을 만들고, 서버는 그 순서대로
파일을 다시 씁니다. 칸 순서가 파일 순서라서 —

**콘솔에서 [작업지점 이름] → [확인 — 적용] 을 한 번 누르는 것만으로 좌우가 뒤집혔습니다.**

이제 **저장된 파일 순서를 그대로** 내보냅니다. 새로 찍은 지점만 뒤에 붙습니다.

### 3. 수동 조작 중에는 **전방 장애물 표시를 숨김**

수동 조작에서는 감속·정지 판정이 **아예 돌지 않습니다.** 그런데도 표시가 남아 있어
같은 값만 계속 떠 있었습니다. 표시를 숨기고, **뒤에서 돌던 조회도 멈춥니다.**

> 이 표시는 **0.3초마다** 서버를 조회합니다. 수동 조작 중에는 쓸모없는 조회가
> 초당 3회씩 LTE 회선을 계속 쓰고 있었습니다.

### 4. 관제 콘솔 사용 설명서 (`docs\manual\console_manual.html`)

화면 7장 + 상세 7장, 모두 14쪽. 화면마다 **색 테두리로 표시한 곳**을 아래 표에서
설명하고, 다음 쪽에서 **버튼을 누르면 로봇이 어떻게 움직이는지**를 순서로 적었습니다.
