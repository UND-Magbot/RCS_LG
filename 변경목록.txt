1. ★ 경유지가 안 쓰이던 문제 — 원인 2개, 둘 다 수정
════════════════════════════════════════════════════════════════
[원인 A] 벽 검사가 선분의 양 끝까지 봤다
    출발점은 로봇이 지금 서 있는 자리다. 충전소에 도킹해 있거나 작업지점에
    서 있으면 벽이 0.7m 안에 있다. 목표점(R/J)도 마찬가지다.
    -> 출발점에서 나가는 모든 연결이 막힘 -> 경로 없음 -> 경유지 0개
    조치: 양 끝 0.80m 는 검사하지 않는다.

[원인 B] 경유지를 '건너뛰어도 되는 힌트' 로 다뤘다  <- 설계가 틀렸다
    경유지는 "이 길로만 다녀라" 고 지정한 통로다.
    조치: 통로 = 인접한 경유지끼리의 체인. 들어간 지점부터 나오는 지점까지
          전부 순서대로 거친다.
          ※ '순서' 는 번호 오름차순이 아니라 **진행 방향** 이다.
            W3->W2->W1 같은 역순도 정상이다.

2. ★ 번호는 통로를 따라 한 방향으로 연속해서 매길 것
════════════════════════════════════════════════════════════════
누가 누구의 이웃인지를 번호가 정하기 때문이다.

  올바름                              잘못됨
    W1 … W10 ┐                         W10 … W1 ┐
    (J1끝 -> 코너)  C1                  (J1끝 <- 코너)  C1
    W11 … W15 ┘                         W11 … W15 ┘
                                     -> W10—W11 이 맵을 가로지르는 간선이 된다

실측 — 잘못 매기면 R2->J2 가 "W10->W11->…" 로 나온다.
       W10(J1끝)에서 W11(코너)로 20m 를 직선으로 건너뛰고,
       그 사이 W9~W1 을 전부 무시한 채 맵을 가로지른다.

중간 번호를 지우는 건 괜찮다. 정렬 목록에서 이웃끼리 다시 이어진다.
  실측: W5·W6 을 지워도 "… W8->W7->W4->W3 …" 로 체인 유지

5. 조용히 빠져나가던 경로에 로그 추가
════════════════════════════════════════════════════════════════
  "경유지 N개 중 M개 사용"              -> 정상 (M이 0이 아니면 동작 중)
  "경유지(W1,W2…)를 하나도 못 찾음"     -> POI 이름이 W+숫자 인지,
                                          로봇 area 와 맵 area 가 같은지
  "현재 위치를 못 읽어 경유지를 건너뜀"  -> 로봇 통신 문제
  "경유지 그래프에서 경로를 못 찾음"     -> 경유지 배치 문제
