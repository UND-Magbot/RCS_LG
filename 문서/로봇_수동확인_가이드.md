## 3단계 — 움직이기 전 안전 점검 (꼭)

### 물리 확인
- [ ] 로봇 주변에 사람·장애물 없음
- [ ] 비상정지 버튼 위치 파악
- [ ] **잭이 올라가 있는지 눈으로 확인** (랙을 든 상태인지)

### 잭이 올라가 있으면 → 먼저 내리기
잭이 올라간 채로 부팅되면(`jack_in_up_state`) **align/charge 명령이 전부 506으로 거부**됩니다.

rb-admin에서 잭 다운 하거나, 안 되면 브라우저 확장/도구로:
```
POST http://192.168.39.100:8090/services/jack_down
```

> 잭 상태 판단 요령: `/jack_state` 의 `state:"hold"` 는 **위/아래와 무관**(모터 정지 유지일 뿐).
> 실제 높이는 **`progress`** 로 봅니다 — `0.0` = 완전 내려감, `1.0` = 완전 올라감.

### 명령을 받는데 제자리면 → 위치추정 소실
SLAM이 `inactive` / quality 0 이면 **로봇이 자기 위치를 몰라서** 명령을 받고도 안 움직입니다.
→ **rb-admin에서 수동 Relocate**(지도에서 로봇을 실제 위치로 드래그)

## 6. ⚠️ 하지 말 것

**rb-admin 수동 조작과 관제(배차)를 섞지 마세요.**

관제 배차는 DB 세션 + 메모리 워커로 로봇 상태를 추적하는데, rb-admin으로 수동 조작하면 **세션이 안 닫혀서 꼬입니다.** (VESA에서 "가용 로봇 0대" 사고의 원인)

- 오늘처럼 **"움직이는지만 보는 것"** → **rb-admin만** 사용, 관제 배차는 건드리지 않기
- 배차 테스트를 할 거면 → 관제/콘솔만 사용, rb-admin 수동조작 금지
- 이미 꼬였으면 → 관제 원격제어의 **[작업 강제 종료]** 로 세션만 정리

**"로봇 호출(렉 포함)"은 픽업(align + jack_up)을 자동으로 합니다.** 미리 잭업 해두면 오히려 506으로 충돌합니다.

## 7. 자주 겪는 문제

| 증상 | 원인 | 해결 |
|---|---|---|
| rb-admin에 맵이 검게/안 뜸 | 로봇 **부팅 중** | `/maps/{id}.png` 가 503→200 되는지, `/chassis/status` 정상인지 확인 후 Ctrl+F5 |
| 명령은 받는데 제자리 | 위치추정 소실 | rb-admin **Relocate**(수동 드래그) |
| align/charge가 506 거부 | 잭이 올라간 상태 | `jack_down` 먼저 |
| 관제 지도에서 마커 안 움직임 | 지도에서 **"로봇 연결"** 을 안 함 | "위치재조정"과 "로봇 연결"은 별개 — 연결해야 실시간 이동 |
| 백엔드 로그 `속도 설정 실패` | 로봇에 못 닿음 | 망 확인. 닿으면 사라짐 |
| 태블릿에서 접속 안 됨 | 태블릿이 다른 망 | 태블릿도 TC700 망으로 |

## 8. 끝나면 (s300 으로 옮기기)

디버깅은 인터넷 되는 `s300` 에서 하기로 했으니, 확인이 끝나면 로봇을 옮깁니다.

1. 로봇 **전원 버튼 9~10회 연타** → 로봇 핫스팟 켜짐
2. PC Wi-Fi를 **로봇 핫스팟**(SSID = 로봇 시리얼 `B682406903516UI` 로 추정) 에 연결, 비번 `12345678`
3. 브라우저 → `http://192.168.12.1:8000/wifi_setup/`
4. **Route Mode Setup: `wlan0_first` → 먼저 submit**
5. **WIFI Setup: `station(Advanced)`**, wifi `s300`, 비번 `12345678`, 고정IP JSON:
   ```json
   {"ipv4.method":"manual","ipv4.address":"192.168.30.110/24","ipv4.gateway":"192.168.30.1","ipv4.dns":"192.168.30.1"}
   ```
   → submit
6. PC Wi-Fi를 `s300` 으로
7. 확인: `http://192.168.30.110:8090/rb-admin` 열리면 성공
8. DB `robots.ip_address` 를 `192.168.30.110` 으로 변경 (Claude에게 요청하면 처리)

⚠️ 세 번째 자리(`30`) 절대 바꾸지 말 것. 끝자리만.
⚠️ **바꾸기 전에 현재 LTE 설정값(SSID·IP)을 캡처**해두면 나중에 되돌리기 쉽습니다.
